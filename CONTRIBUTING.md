# Contributing

Meerkat MFT is in early development, and outside code contributions aren't accepted yet. Pull requests from outside the project will be closed until a contributor agreement has been chosen.

## What's welcome

- **Bug reports:** open a GitHub issue with what you did, what you expected, and what happened.
- **Questions and design feedback:** open a GitHub issue. The decisions so far are in [docs/adr/](docs/adr/).

## Security issues

Don't open a public issue for a security problem. Follow [SECURITY.md](SECURITY.md) instead.
